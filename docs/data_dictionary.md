# Data Dictionary

| Table | Purpose |
|---|---|
| customers | Customer master data |
| categories | Product categories |
| products | Product catalog and unit economics |
| orders | Order-level transactions |
| order_items | Product lines within orders |
| payments | Payment transactions |
| returns | Returned order items and refunds |
| reviews | Customer product ratings |
| campaigns | Marketing campaigns |
| customer_campaigns | Customer campaign participation |
| customer_events | Behavioral events |

All monetary fields use NUMERIC rather than floating-point types.
